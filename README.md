BMP

Бизнес-процесс - это устойчивая, повторяющаяся последовательность действий, которую компания выполняет для создания ценности для клиента или достижения конкретной бизнес-цели. У бизнес-процесса всегда есть вход (запрос, заявка, сырье) и выход (результат, продукт, услуга), его выполнение можно измерить и улучшить.

Примеры из разных сфер:

1. Логистика ("Возврат товара") - Заявка → проверка, оформление, возврат денег → принятый возврат
2. IT-поддержка ("Закрытие тикета") - Запрос пользователя → диагностика, решение → закрытый инцидент
3. HR ("Онбординг сотрудника") - Подписанный оффер → подготовка места, выдача оборудования, обучение → готовый сотрудник
